# NYC staff email downloads

Admin login or Bulk download opens the owner controls. Create download link can optionally bind an invitation to one email; otherwise the invitation can be shared with multiple staff. The recipient enters their email without signing in, and receives a ZIP-ready email. All visible photos from both groups are included as JPEG web renditions. The same delivery email includes a separate Download videos button for the view-only NYC Dropbox video folder. The folder download uses dl=1 and includes its current contents, including later uploads. The photo ZIP remains JPEG-only. The Dropbox viewing link has downloads enabled and no expiry; it can be revoked in Dropbox sharing settings. Verified October 26: one MOV, 8,208,348 bytes.

Requests enqueue the separate `nyc-photo-exports` topic. A dedicated NYC callback handles these messages; London source collection is neither called nor scheduled by this feature. Archives stream in bounded 5 MiB multipart uploads. Job/contact state is AES-256-GCM encrypted with the dedicated NYC_EXPORT_KEY. Raw archives use unguessable 256-bit object paths, short signed download URLs, and a queued cleanup after 48 hours. Download authorization rechecks visibility before releasing a link; hidden photos invalidate an older archive. Recipients may retry downloads until expiration.

New invitations last five days. The initial owner-requested staff invitation is valid through November 2, 2026, Eastern time. The server refuses to enable invitations if its secret is missing. Requests are limited per invitation/hour and deduplicated by invitation/email. Worker leases and retries prevent concurrent builds; email sends use the job idempotency key. Email provider configuration stays in the authenticated Supabase edge function; no credentials are sent to the browser. The whole-album manifest count is checked so a truncated gallery cannot silently become an incomplete ZIP.

Tests cover encryption/tamper rejection, multipart chunk order and abort, recipient email request UI, administrator isolation, incomplete-manifest rejection, and ZIP correctness in the existing streaming-writer suite.
