# RCAP treasurer ledger

The reimbursement database is the record of truth. The [read-only Google Sheet](https://docs.google.com/spreadsheets/d/1M5XRQp56NytaV8bYh6-f4aotsg6J7v3raSfiiKmnRuI/edit) is a convenient live view for reconciliation. `Requests` has one row per site request, including archived and test requests, with payment method and Zelle destination. `Expenses` has one row per expense with its vendor, receipt total, amount requested from RCAP, coverage note, receipt names, and dated notes added after approval. `History` has one row per action, including those expense notes. `Notifications` records each email or text dispatch, its recipients, send status, and any provider delivery status. A sent notice means the provider accepted it, not necessarily that it reached an inbox or handset. The Documents column opens a private Drive folder for that request. The original uploads and generated PDF records are copied into those folders.

The Sheet is shared as a reader with `lemeri@abc-seniors.com` and `rcaparents@ronclarkacademy.com`. Its [document parent folder](https://drive.google.com/drive/folders/1NOfAhq2gBLmR761EKUgWjsXkMtI8HRqE) must have the same reader access. Do not enable public link access.

The [Apps Script project](https://script.google.com/home/projects/1lIf395oiOy16ERgAj06UVWEUUdFwwVhAFlYiPjn_LSPbLOTp6CPc3Z7T/edit) holds `Code.gs`. Its `installLedger` function gives the two readers access to the document folder, sets up the Sheet, runs an immediate sync, and installs a five-minute timer. It is safe to rerun: existing documents are matched by source path digest and are not copied twice. It reads a secret from the `RCAP_LEDGER_KEY` Script Property. The secret is never stored in this repository or in a Sheet cell. Only the key hash is in the private database config. Rotate both values together if the key is exposed.

The service-only `cr_ledger_snapshot` RPC checks the key and returns all requests, history, and delivery metadata. It does not export notification bodies. The `check-request-ledger` Edge Function adds ten-minute signed source-file links and extracts expense lines. Apps Script copies the files into Drive, then rewrites all four Sheet tabs. If the source or any document fails, that sync fails and retries on the next timer run. The browser app only links to the Sheet for finance roles; it never sees the export key.
